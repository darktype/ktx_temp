# 모바일티머니 자동출석 안드로이드 앱 (순정 폰 지원)

루팅되지 않은 안드로이드 순정 폰에서도 **안드로이드 공식 접근성 서비스(Accessibility Service)**를 활용하여 모바일티머니 출석체크를 매일 자동으로 수행하고, Synology NAS(`https://darktype.synology.me:7878`)로 결과를 전송하는 독립형 앱입니다.

---

## 🌟 주요 기능

1. **무루팅(순정 폰) 자동화**:
   - `AccessibilityService`를 통해 화면의 `출석하기` 버튼을 정밀 감지하고 자동 터치
   - 출석 결과 팝업("1M 적립되었습니다") 파싱 후 자동 닫기
   - 이미 출석한 상태(already_done) 예외 처리
2. **정확한 알람 스케줄러**:
   - `AlarmManager` 기반 매일 정해진 시각(기본: 오전 09:00)에 화면을 깨우고 앱 자동 실행
3. **Synology NAS 대시보드 리포트**:
   - 출석 결과(성공 여부, 적립 마일리지, 타임스탬프)를 NAS 대시보드 API로 자동 전송

---

## 🚀 1분 만에 APK 빌드하는 방법 (GitHub Actions)

컴퓨터에 Android Studio나 Java/SDK를 설치할 필요 없이, GitHub 무료 클라우드 서버에서 1분 만에 APK를 자동 빌드할 수 있습니다.

1. **`APK_자동빌드_업로드.bat` 실행**:
   - 폴더 내의 `APK_자동빌드_업로드.bat`을 더블 클릭합니다.
2. **GitHub 빈 저장소 연결**:
   - GitHub에서 새로 만든 저장소 주소(예: `https://github.com/사용자명/tmoney-auto-app.git`)를 입력합니다.
3. **[🚀 GitHub로 코드 업로드 및 APK 자동 빌드 시작] 클릭**:
   - 코드가 자동으로 GitHub에 업로드되고, GitHub Actions에서 빌드가 시작됩니다.
4. **APK 다운로드**:
   - 열린 GitHub 저장소의 **Actions** 탭에서 생성된 **`TmoneyAuto-Debug-APK`**를 다운로드하여 휴대폰에 설치합니다.

---

## 📱 휴대폰 설치 후 설정

1. **접근성 권한 허용**:
   - 앱 실행 후 **[⚙️ 접근성 설정 열기]** 클릭
   - 설치된 앱 중 **[모바일티머니 자동출석]**을 찾아 **'사용 중(허용)'**으로 켭니다.
2. **배터리 최적화 제외**:
   - **[🔋 배터리 최적화 제외 설정]** 클릭 후 '허용'을 선택합니다.
3. **실행 시각 및 NAS 주소 확인**:
   - 기본 실행 시각: 매일 오전 09:00
   - NAS URL: `https://darktype.synology.me:7878`
